# 🔥 GitHub 全球爆款开源项目每日精选

基于 GitHub Actions 与 GitHub Pages 的开源项目每日推送系统，全自动抓取 AI 智能体、前沿开发者工具及全栈高分项目。

---

## 🌟 核心亮点

1. **🎨 Anthropic 品牌社论美学**：暖沙色纸质背景（`#FAF7F2`）、赤陶珊瑚红（`#D97757`）与典雅衬线字体（Noto Serif SC / Merriweather）。
2. **🌓 动态日夜间主题**：支持在 Anthropic Daylight（日光模式）与 Anthropic Dusk（夜间模式）随意切换。
3. **⭐ 精选分类卡片**：自动提取星标数（Stars）、语言类型、Topic 标签及项目介绍。
4. **⚙️ 零成本云端自动化**：通过 GitHub Actions 每天早晨 8:00 自动运行并更新部署到 GitHub Pages。
